# 智丽 AI 助手

**ZhiLi AI Assistant**
HackJunction 作品说明底稿 · 候选版本 1.0.0（versionCode 119）

## 作品简介

智丽 AI 助手是运行于 IrisView ARUI 的日常生活助手。用户可以通过语音或文字发起请求，在同一段对话中继续追问或补充信息。应用提供本地备忘、待办、提醒和日程记录，并可浏览持久化的历史对话。它希望让日常信息记录和查询更自然，减少在语音、文字和应用页面之间切换的负担。

## 交互流程与功能

应用启动后进入对话界面并显示当前状态。用户可提交文字，或通过设备语音入口录音；语音由 Qwen Audio 识别后进入与文字相同的助手处理流程。明确的备忘、待办、提醒和日程命令在本地处理并保存；普通聊天及需要模型处理的问题发送到 Qwen 大语言模型。请求结果显示在对话中，状态栏区分待命、处理中、待确认、完成和异常。

历史会话保存在应用私有数据目录，当前实现最多保存最近 50 段会话、每段最多 200 条消息。用户可通过历史选择界面查看会话、使用方向键滚动内容并返回当前对话。历史选择、返回和再次进入已在候选模拟器验收通过。

## 技术实现

- 平台：IrisView Developer Kit，ARUI/FusionUI 窗口应用。
- 输入：平台文字输入、导航按键和音频采集。
- 语音识别：`qwen-audio-3.1-asr-flash-message`，通过 WebSocket 流式传输音频并接收识别结果。
- 对话模型：`qwen3.8-flash`，通过兼容 Chat Completions 的 HTTP API 返回结构化 JSON。
- 本地数据：对话历史及日常记录写入平台提供的应用私有数据目录。
- 依赖：项目清单没有 npm 第三方运行时依赖；运行环境依赖 IrisView Client/Developer Kit。
- 密钥：通过本地环境变量 `DASHSCOPE_API_KEY` 注入；密钥不进入源码、应用包或提交材料。
