# 作品声明

## 数据

- 应用保存用户输入的对话历史和用户创建的备忘、待办、提醒、日程，存储于 IrisView 提供的应用私有数据目录。
- 用户主动发起语音请求时，音频帧发送到配置的语音识别服务；文字请求及必要的对话上下文发送至配置的大语言模型服务。
- 数据保留上限：最多 50 段对话、每段最多 200 条消息。竞赛测试账号和测试数据应使用虚构内容。
- 参赛者确认已核实 Qwen 服务条款，并允许在验收中向服务发送虚构语音/文字测试数据及必要上下文。

## AI 使用

- 运行时语音识别模型：Qwen Audio `qwen-audio-3.1-asr-flash-message`。
- 运行时大语言模型：Qwen `qwen3.8-flash`。
- AI 用于语音转写、普通对话及联网问题处理；AI 辅助了部分开发工作。AI API Key 仅通过本地环境变量配置，不随应用或提交材料提供。
- 联网搜索能力依赖服务端和网络；未经赛事模拟器实测的部分不声明为已通过。
